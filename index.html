1快速安装

GitHub 仓库 下载 zip 包含安装 / 卸载脚本、打好补丁的文件、diff、导入工具
  1. 准备环境。装好 Node 20+（推荐 nvm）和 Claude Code CLI，在终端里运行一次 claude 并用订阅账号登录。
  2. 下载并安装。 
    git clone https://github.com/Amewiki777/cloudcli-kit.git && cd cloudcli-kit
./install.sh
    如果你的 Claude 要走本地代理（比如 Clash），把端口告诉脚本，它会写进常驻服务的环境变量： 
    PROXY=http://127.0.0.1:7897 ./install.sh
  3. 打开 http://localhost:3001。脚本跑完会自动打开。开机自启，不用再手动启动。

脚本依次做的事：装固定版本 1.37.3 → 把 files/ 覆盖进包目录（原文件备份成 *.orig）→ 按你本机的 node / claude 路径生成 launchd 配置并启动 → 注册一个占位用户、跳过首次引导。可以反复运行。

2改了什么、为什么

#定制为什么改动位置
1免登录，只监听 127.0.0.1原版强制注册账号、默认监听 0.0.0.0。自己本机用，登录是多余的.env、dist/index.html
2只显示 Claude 会话原版会把 Codex 等其它工具的会话也混进列表两个 service 文件
3标题和 Claude 客户端一致，隐藏脚本会话原版取第一条输入当标题，会出现 /model 这种；claude -p 脚本产生的大量一次性会话会刷屏claude-session-synchronizer.provider.js
4额度胶囊（右下角）随时看 5 小时 / 本周 / 本周 Fable 用量和重置时间，每 60 秒刷新新增 claude-usage.patch.js
5模型标签带版本号原版只写 Opus / Sonnet，分不清是哪一代claude-models.provider.js
6文件名旁的 「打开 ▾」菜单Claude 改了哪个文件，点一下用默认程序 / 指定编辑器打开、在 Finder 中显示，或预览 Markdown新增 local-file.patch.js
7粘贴任意文件原版粘贴只收图片，PDF、表格只能拖拽dist/index.html
8公式用 LaTeX网页端能渲染 KaTeX，但 Claude 默认按终端习惯写纯文本公式claude-runtime.provider.js

每一项的具体代码见 第 8 节。

3安全须知

不要对局域网开放 免登录模式下，服务端把任何请求都当成同一个用户；「打开文件」和「额度」接口也没有鉴权。只要别人能连上这个端口，就等于能在你的电脑上让 Claude 执行命令。.env 里的 HOST=127.0.0.1 一定不要改成 0.0.0.0。

如果确实要从手机或别的电脑访问，先恢复登录：删掉 .env 里的 VITE_IS_PLATFORM=true，并把 dist/index.html 恢复成 index.html.orig（会丢掉额度胶囊等前端补丁，需要的话只去掉 <title> 后面那行写 auth-token 的脚本）。

5踩过的坑

  • 新版 npm 提示原生模块的安装脚本未获批准（bcrypt、better-sqlite3、node-pty）：可以忽略，这几个包自带 macOS 预编译文件。只有以后换了 Node 大版本、启动报错时，才需要进包目录运行 npm rebuild bcrypt better-sqlite3 node-pty。
  • EADDRINUSE（端口被占用）：通常是之前手动起的实例还在。用 lsof -nP -t -iTCP:3001 -sTCP:LISTEN 找到 PID 再 kill；pkill -f cloudcli 不一定杀得干净。旧实例占着端口时 launchd 会反复重启。
  • 用 nohup 后台启动会被回收：所以改成了 launchd 常驻。launchd 不读 .zshrc、不加载 nvm，plist 里 node 和 claude 的路径必须是绝对路径；需要代理也得在 plist 里单独写。
  • 首次引导的 Git 配置页过不去：没有跳过按钮，邮箱校验也很严。安装脚本直接调 /api/user/complete-onboarding 跳过了。
  • 会话链接里的 id 和 JSONL 文件名对不上：localhost:3001/session/<id> 用的是 CloudCLI 自己的编号。对应关系在 auth.db 的 sessions 表（session_id / provider_session_id / jsonl_path）。
  • 同一个对话开多个标签页：每个页面都会起一个 Claude 进程，长任务会互相干扰。一个对话只开一个页面。
  • 网页端会话没有 Chrome 扩展工具：需要操作 Chrome 时，去终端用 claude --chrome。
  • 额度胶囊只对订阅登录有效：用 API key、Bedrock、Vertex 登录时显示不可用。

6导入 Claude 桌面客户端

CloudCLI 和桌面客户端读的是同一批对话记录，但客户端左侧列表只显示它自己建过的会话。tools/import_to_claude_desktop.py 会为其余对话补一个列表项（只新建小 JSON 文件，不改对话记录），之后在客户端里也能接着聊。

python3 tools/import_to_claude_desktop.py          # 试运行：统计 + 预览标题
python3 tools/import_to_claude_desktop.py --apply  # 写入

写入后按 ⌘Q 完全退出 Claude 客户端再打开。标题优先用原有标题，没有就取第一句话的前 50 个字；claude -p 脚本产生的会话、工作目录已删除的会话会自动跳过。撤销：删掉文件里带 "importedBy": "cloudcli-kit" 的 local_*.json。

别两边同时聊同一个会话 CloudCLI 和客户端会往同一个记录文件里写，同时发消息会让记录错乱。

7手动搭建（不用脚本）

想自己一步步来，或者不是 macOS：

  1. npm install -g @cloudcli-ai/cloudcli@1.37.3，然后 PKG="$(npm root -g)/@cloudcli-ai/cloudcli"。
  2. 把压缩包里 files/ 下的文件按相同相对路径覆盖进 $PKG（或在 $PKG 里 patch -p1 < patches.diff）。其中 .env 内容： 
    VITE_IS_PLATFORM=true
HOST=127.0.0.1
  3. 前台试跑：node "$PKG/dist-server/server/modules/cli/cli.js"，打开 localhost:3001。
  4. 注册占位用户并跳过引导（密码随机，之后用不到）： 
    curl -X POST localhost:3001/api/auth/register -H 'Content-Type: application/json' \
  -d "{\"username\":\"local\",\"password\":\"$(openssl rand -hex 16)\"}"
curl -X POST localhost:3001/api/user/complete-onboarding -H 'Content-Type: application/json' -d '{}'
  5. 常驻：macOS 用 launchd（见下面 install.sh 里生成的 plist），Linux 可写一个 systemd --user 服务。文件菜单里的「打开」依赖 macOS 的 open 命令，其余功能跨平台。
install.sh一键安装脚本全文
#!/bin/bash
# CloudCLI 本机定制版一键安装（macOS）
#   用法:  ./install.sh                         # 不走代理
#          PROXY=http://127.0.0.1:7897 ./install.sh   # Claude 需要走本地代理时
# 做的事: 装 @cloudcli-ai/cloudcli@1.37.3 → 覆盖补丁文件 → 写 launchd 常驻 → 注册占位用户并跳过引导
# 前提:   已装 Node 20+ 和 Claude Code CLI，并且终端里 `claude` 已登录（订阅账号）
set -euo pipefail

VERSION=1.37.3
PORT=3001
LABEL=com.cloudcli.server
KIT="$(cd "$(dirname "$0")" && pwd)"
PLIST="$HOME/Library/LaunchAgents/$LABEL.plist"

say() { printf '\033[1;34m==>\033[0m %s\n' "$*"; }
die() { printf '\033[1;31m错误:\033[0m %s\n' "$*" >&2; exit 1; }

[[ "$(uname)" == Darwin ]] || die "这个脚本只支持 macOS（launchd、open 命令都依赖它）"
NODE="$(command -v node)" || die "找不到 node，请先装 Node 20+（推荐 nvm）"
command -v npm >/dev/null || die "找不到 npm"
CLAUDE="$(command -v claude)" || die "找不到 claude，请先装 Claude Code CLI 并登录"
NODE_MAJOR="$("$NODE" -p 'process.versions.node.split(".")[0]')"
(( NODE_MAJOR >= 20 )) || die "Node 版本太旧（$("$NODE" -v)），需要 20 以上"

# 1. 安装固定版本：补丁依赖 1.37.3 的文件结构，别装最新版
say "安装 @cloudcli-ai/cloudcli@$VERSION"
npm install -g "@cloudcli-ai/cloudcli@$VERSION"
PKG="$(npm root -g)/@cloudcli-ai/cloudcli"
[[ "$("$NODE" -p "require('$PKG/package.json').version")" == "$VERSION" ]] || die "装上的版本不是 $VERSION"

# 2. 覆盖补丁文件，原文件第一次覆盖前备份成 *.orig
say "应用补丁到 $PKG"
cd "$KIT/files"
find . -type f | while read -r f; do
  dst="$PKG/${f#./}"
  mkdir -p "$(dirname "$dst")"
  [[ -f "$dst" && ! -f "$dst.orig" ]] && cp "$dst" "$dst.orig"
  cp "$f" "$dst"
done
cd "$KIT"

# 3. launchd 常驻。launchd 不读 shell 配置，所以 node / claude 的目录都写成绝对路径
say "写入 $PLIST"
mkdir -p "$HOME/.cloudcli" "$HOME/Library/LaunchAgents"
PATH_VALUE="$(dirname "$NODE"):$(dirname "$CLAUDE"):/opt/homebrew/bin:/usr/local/bin:/usr/bin:/bin"
PROXY_XML=""
if [[ -n "${PROXY:-}" ]]; then
  for k in http_proxy https_proxy HTTP_PROXY HTTPS_PROXY; do
    PROXY_XML+="    <key>$k</key><string>$PROXY</string>"$'\n'
  done
  for k in no_proxy NO_PROXY; do
    PROXY_XML+="    <key>$k</key><string>localhost,127.0.0.1,::1</string>"$'\n'
  done
fi
cat > "$PLIST" <<EOF
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key><string>$LABEL</string>
  <key>ProgramArguments</key>
  <array>
    <string>$NODE</string>
    <string>$PKG/dist-server/server/modules/cli/cli.js</string>
  </array>
  <key>WorkingDirectory</key><string>$HOME</string>
  <key>EnvironmentVariables</key>
  <dict>
    <key>PATH</key><string>$PATH_VALUE</string>
    <key>HOME</key><string>$HOME</string>
$PROXY_XML  </dict>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
  <key>ThrottleInterval</key><integer>5</integer>
  <key>StandardOutPath</key><string>$HOME/.cloudcli/server.log</string>
  <key>StandardErrorPath</key><string>$HOME/.cloudcli/server.log</string>
</dict>
</plist>
EOF
plutil -lint "$PLIST" >/dev/null

# 端口被旧实例占着时 launchd 会无限重启，先清掉
OLD_PID="$(lsof -nP -t -iTCP:$PORT -sTCP:LISTEN 2>/dev/null || true)"
launchctl bootout "gui/$(id -u)/$LABEL" 2>/dev/null || true
[[ -n "$OLD_PID" ]] && { say "结束占用 $PORT 端口的旧进程 $OLD_PID"; kill $OLD_PID 2>/dev/null || true; sleep 1; }
launchctl bootstrap "gui/$(id -u)" "$PLIST"

say "等待服务启动"
for _ in $(seq 1 30); do
  curl -fsS "http://127.0.0.1:$PORT/" >/dev/null 2>&1 && break
  sleep 1
done
curl -fsS "http://127.0.0.1:$PORT/" >/dev/null 2>&1 || die "服务没起来，看日志: tail -50 ~/.cloudcli/server.log"

# 4. 注册占位用户（免登录模式下所有请求都映射到第一个用户，密码随机生成后不再使用）
say "注册占位用户 local 并跳过首次引导"
PW="$(openssl rand -hex 16)"
curl -fsS -X POST "http://127.0.0.1:$PORT/api/auth/register" \
  -H 'Content-Type: application/json' -d "{\"username\":\"local\",\"password\":\"$PW\"}" >/dev/null 2>&1 \
  || echo "   （已有用户，跳过注册）"
curl -fsS -X POST "http://127.0.0.1:$PORT/api/user/complete-onboarding" \
  -H 'Authorization: Bearer local' -H 'Content-Type: application/json' -d '{}' >/dev/null 2>&1 || true

say "完成 → 打开 http://localhost:$PORT"
echo "   日志:   tail -f ~/.cloudcli/server.log"
echo "   重启:   launchctl kickstart -k gui/\$(id -u)/$LABEL"
echo "   卸载:   ./uninstall.sh"
open "http://localhost:$PORT" || true

def find_meta_dir():
    # <账号>/<组织> 目录里放着现有会话的 local_*.json；取最近用过的那个
    dirs = [d for d in glob.glob(os.path.join(SESSIONS_ROOT, "*", "*")) if os.path.isdir(d)]
    if not dirs:
        sys.exit("找不到桌面客户端的会话目录：先在 Claude 桌面客户端的 Code 标签页里随便开一个会话")
    return max(dirs, key=os.path.getmtime)


def encode(path):
    return re.sub(r"[^A-Za-z0-9]", "-", path)


def to_ms(ts):
    return int(datetime.fromisoformat(ts.replace("Z", "+00:00")).timestamp() * 1000)


def short_title(text):
    text = re.sub(r"<command-name>(.*?)</command-name>", r"\1 ", text)
    text = re.sub(r"<[^>]+>[^<]*</[^>]+>", "", text)
    return re.sub(r"\s+", " ", text).strip()[:50]


def scan(path):
    info = dict(ts=[], cwds=[], model=None, custom=None, ai=None, first=None, mode=None, entry=set())
    for line in open(path, errors="ignore"):
        try:
            d = json.loads(line)
        except ValueError:
            continue
        kind = d.get("type")
        if d.get("timestamp"):
            info["ts"].append(d["timestamp"])
        if d.get("cwd") and d["cwd"] not in info["cwds"]:
            info["cwds"].append(d["cwd"])
        if d.get("entrypoint"):
            info["entry"].add(d["entrypoint"])
        if kind == "custom-title":
            info["custom"] = d.get("customTitle")
        elif kind == "ai-title":
            info["ai"] = d.get("aiTitle")
        elif kind == "permission-mode":
            info["mode"] = d.get("permissionMode")
        msg = d.get("message") or {}
        if kind == "assistant" and msg.get("model") and not msg["model"].startswith("<"):
            info["model"] = msg["model"]
        if info["first"] is None and kind == "user" and not d.get("isMeta"):
            content = msg.get("content")
            if isinstance(content, list):
                content = " ".join(x.get("text", "") for x in content if isinstance(x, dict) and x.get("type") == "text")
            if content and content.strip():
                info["first"] = content
    return info
